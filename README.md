# Form Submission for Tech Events in Tamil Nadu

## Setup

1. **Clone the repository:**
	
	```bash
	git clone https://github.com/Tharun-Kumar-A-01/register-event.git
	```

2. **Create a virtual environment:**

	```bash
	python -m venv venv
	```

3. **Install requirements:**
	
	```bash
	pip install -r requirements.txt
	```

4. **Environment Configuration:**
   Create a `.env` file and add necessary credentials.

5. **Run the Application:**

	```bash
	python app.py
	```

## Features

- **Event Submission:** Streamlined form for tech organizers to list events.
- **Location Filtering:** Targeted support for cities across Tamil Nadu (Chennai, Coimbatore, Trichy, etc.).
- **Validation:** Built-in checks for date, time, and venue details.
